# A-Task-Management-Application

A simple task manager built using **Flask** and **SQLite3**.

## Features

- Add new tasks with a title and description
- Edit task details and mark them as 'Pending' or 'Completed'
- Delete tasks
- View all tasks on the homepage

## Technologies Used

- Python
- Flask
- SQLite
- HTML (Jinja2 templates)

## Install dependencies:

pip install Flask

## Run the app:

python app.py

## Open in browser:
example:
http://127.0.0.1:5000/
